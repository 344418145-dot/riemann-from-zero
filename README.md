# 从零理解黎曼猜想 — 交互课程原型（v0.2 · 九节互动课程）

**目标**：让数学基础薄弱的学习者在不背结论的情况下，通过逐步操作理解函数、无穷级数、复数，以及最终的黎曼猜想。

## 立即运行

直接双击 `index.html`，或使用任意静态 Web 服务器：

```bash
cd riemann-from-zero
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

运行课程无需安装 npm、无需后端。手机端自适应布局；浏览器可保存本机学习进度。Google Fonts 不能加载时自动使用本地字体。npm 依赖只用于开发验收。

## 已实现（9 个可以独立完成的互动课程）

1. **函数机器**：修改输入，实时观察 `f(x)=2x+1` 的输出；理解函数名与输入变量的区别。
2. **ζ(2) 无穷级数**：调整求和项数 1–200，观察部分和、极限、收敛图形；明确有限项 ≠ 无穷和。
3. **乘以 i 的旋转**：点击乘以 `i`，让复平面箭头每次旋转 90°；看到 `1 → i → −1 → −i → 1`。
4. **复数坐标**：分别调整 `a` 和 `b`，看 `a+bi` 在复平面上的位置。

5. **欧拉公式与自然对数**：拖动单位圆角度，查看 cos、sin 及 2ⁱ 的位置。
6. **Eta 函数与解析延拓入门**：从 ζ(2) 偶数项推导交错级数，比较有限部分和与真实极限。
7. **第一个非平凡零点**：用经过欧拉收敛加速的 Eta 数值计算，在临界线上接近 14.134725…i；注明近似与证明的区别。
8. **临界带与 1/2 对称轴**：成对镜像点可视化，明确是假设点，不代表发现了反例。
9. **质数分布与欧拉乘积**：统计 100–10000 质数数量，比较对数积分近似，并计算有限欧拉乘积。

每节课程有知识说明、交互实验、理解检测和进度记录。没有证明的数学论断不会被讲成已证明事实。

## 课程设计原则

- 具体例子 → 观察变化 → 发现规律 → 推导公式 → 练习验证。
- 新公式必须解释由来和适用范围；不因“为了简单”而引入数学不准确的说法。
- `ζ` 是函数名，`s` 是输入变量，不用 `S` 代替 `ζ`。
- 面向零基础学习者，用「一次一个问题」的方式教学。
- 清楚区分 **已证明的事实、数值近似、直观比喻、尚未解决的猜想**。

## 数学说明

- 原有 `ζ(2)` 互动使用的原始 Dirichlet 级数只用于 `s=2`，这里收敛。
- `ζ(2)=π²/6≈1.6449340668482264` 用作参考极限。
- 新增零点实验通过 Eta 级数的欧拉变换在 0.5+ti（13.5≤t≤14.8）附近进行复数数值计算，采用75层变换；只在规定区间演示，不声称已实现任意复数上的精确解析延拓，也不把显示为0当成数学证明。

## v0.2 数值与教学质量边界

- ζ(s) 的新数值实验使用交错级数的收敛加速，复杂度较低，但并非正式的高精度数学证明。
- `ζ(0.5+14.1347251417…i)` 的输入在界面上只显示有限精度；严格零点是无穷精度的位置。
- 质数计数通过筛法得到，`li(x)` 使用数值积分模拟高斯估算，预测误差不代表零点个数。
- 新课程从具体例子逐步解释结论；完整的 Theta/傅里叶/解析延拓证明不在 v0.2 的基础教学范围内。
